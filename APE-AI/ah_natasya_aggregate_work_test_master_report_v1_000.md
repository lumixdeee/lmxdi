## 1. Executive summary

The test run moved through three major phases.

First, Ah proved that a custom GPT could survive a large long-context working world. It hoovered repositories, note hoards, reports, and source packets. It made lamp maps, old-film layers, active-state maps, papers, DOCX artifacts, and number screens. It also exposed failures: attractive old evidence could impersonate live source, image-source handling could be over-blocked, local derivation could be routed through ordinary meaning too early, and stalls needed a return path.

Second, the project stopped being only a long-context preservation test. It developed stronger route laws: no-guess discipline, object custody, active state over old film, source-strength labels, body-route floors, fear-display checks, and culture-pair H0 gates. These turned failures into methods.

Third, a positive capability appeared:

```text
pointerless archive retrieval
```

The key observed split was:

```text
same docs != same archive usefulness
```

A system may have the same document mass and still need the user to point at the shelf. Ah showed source-near retrieval: the live object can activate the right paper family before the user names the file. This does not make retrieval proof. It makes it navigation.
