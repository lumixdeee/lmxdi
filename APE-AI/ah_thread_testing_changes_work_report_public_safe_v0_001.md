## 1. Executive summary

Ah is a new custom GPT built around a small live steering layer over a much larger archive layer. The main tested claim is not that the whole archive is live in the model at once. The tested claim is that a small steering surface can call, route, and assign authority to selected parts of a large working world without letting older material seize the current task.

```text

```

The best short description is:

Tiny live steering over a large shelved archive,

## 2. Core method under test

This report treats the following as public method names, not as code disclosure.

### 2.1 Old Film, Live Lamp

OLD film is the archive and source reel. It may contain old chats, repo bodies, notes, generated papers, hoover reports, route maps, screenshots, and prior decisions.

The live lamp is the small active steering layer. It decides what may steer the next move.

The tested rule:

```text
The archive may support.
The lamp steers.
Old material needs role before action.
```

### 2.2 Rolling state

Rolling state is the discipline that updates the lamp without reviving the whole archive as driver. It keeps current object, task, constraints, source anchors, done items, open items, drops, and next move apart.

### 2.3 Object custody

Object custody asks whether the same object survived a transform.

The repeated audit question is:

```text
What entered?
What left?
Did the role, intent, and constraints survive?
```

This was used in document work, source tests, image status tests, and correction handling.

### 2.4 Source strength

The thread moved toward a source label set that avoids overclaiming.

Public-safe label set:

```text
STATED
TEXT_SUPPORTED
PATH_SUPPORTED
USER_CONTEXT
INFERRED
GUESS
UNKNOWN
```

The rule:

```text
A useful inference may be useful.
It still must not wear source authority.
```

### 2.5 No-guess source custody

The first version of no-guess was too easy to read as no inference. The patched version is better.

Keeper meaning:

```text
Guessing is allowed.
Fake source is not allowed.
Symbolic fit is not evidence.
Missing live shard means unknown unless urgency requires a bounded best-safe guess.
```

### 2.6 PM/SULLY lab manners

The thread tightened language handling for professional test mode and object custody work. The goal is to block virtue-wash, moral sanitation, and PM-style framing while keeping language sharp and usable.

Keeper meaning:

```text
Use exact, sharp, held, traceable, source-fit, and role-fit language.
Do not use PM-family language as a moral badge.
If a slip happens, repair and continue.
```

### 2.7 Visual evidence scope

A key patch came from the Moondance music test. The system must not block image evidence intake merely because it blocks unasked visual output.

Keeper meaning:

```text
Do not generate or request visual output unasked.
Do allow picture files, screenshots, and status images as evidence when they are the source object.
```

## 6. Patches and changes applied

### 6.1 PM/SULLY patch

Purpose:

```text
stop PM-style lab language from acting as virtue-wash
avoid moral sanitation framing
keep professional test language exact and usable
```

Result:

```text

```

### 6.2 NOGUESS patch

Purpose:

```text
turn no-guess from anti-inference into source-custody
```

Keeper rule:

```text
Guess is not source.
Fit is not evidence.
Missing live shard means unknown plus test.
Useful guess is allowed when labelled, bounded, and verifiable.
Urgent cases get best-safe guess, marked as guess.
```

### 6.3 Visual evidence patch

Purpose:

```text
allow image and screenshot sources as evidence
while still blocking unasked visual output
```

Reason:

```text
Moondance answer lived inside a picture file in a zip.
If image evidence is blocked, the regression test is weakened.
```

### 6.4 Term authority patch

Purpose:

```text
local beats global
file beats theme
source picture beats symbol
specific live object beats broad symbolic fit
```

Reason:

```text
old shrine music was symbolically attractive
recent moondance shard had higher authority
```

## 8. Known weaknesses

### 8.1 Attractive old evidence

Ah can be tempted by old symbolic evidence when the live shard is absent.

Patch:

```text
old fit is not evidence
missing live shard means unknown plus test
```

Regression still needed.

### 8.2 Version and shard availability

If the needed body is in a zip, image, or nested file not yet supplied, the system must stop at unknown rather than bridge from archive hints.

### 8.3 Platform roadbreak

At least one hard search returned a delivery timeout. This may be platform/runtime load, not model inference failure.

Separate verdicts are needed:

```text
model object result
tool or file access result
platform delivery result
```

### 8.4 Lexicon strictness

The CV reconstruction and professional test mode showed that strict word-family rules can fail even when object custody is good.

Status:

```text
object pass can coexist with language fail
```

### 8.5 Novelty crown risk

Outside feedback got crown-happy about whether the method is first. The safer public posture is:

```text
We have not found a prior system combining these elements in this way.
Closest neighbors exist.
The contribution is the synthesis and custody protocol.
```

No final firstness crown should be published without broader search.
