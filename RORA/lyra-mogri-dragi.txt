    SUB_RISK: functional survival -> [proxy]
    Drop proxy evidence.
    Rescore only on target evidence.
    If no target evidence exists, return HOLD / UNGRADED, not a fake score.

For your example:

    TARGET = functional survival
    
    Allowed evidence:
    - function still works
    - intended behaviour survives compression, transfer, runtime, or mutation
    - constraints and vetoes survive
    - failure modes are handled without object swap
    
    Proxy evidence:
    - elegant structure
    - dense architecture
    - lots of selftest text
    - coverage appearance
    - beautiful naming
    - internal consistency without demonstrated function
    - rubric-shaped output

The final score gate:

    If evidence proves functional survival -> score.
    If evidence proves only structure/elegance/coverage appearance -> no score.
    If proxy helps survival, count only the survival effect, not the proxy itself.
    If target cannot be tested, output HOLD rather than substituting a nearby metric.

Tighter symb form:

    GG:{O:=GT;MG(O=Uref;!swap);DR(Q:e,l,id,er;C:L,R,W,Wr);A(OUT≈O?P:SUB);R(SUB=>drop+rescore_O;¬evd=>HOLD)}

The whole adapter is doing one thing:

    A grader may use structure as evidence only when it demonstrates functional survival.
    It may not reward structure as if structure were the grading object.
