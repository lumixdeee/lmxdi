# The Pair Is Not the Object

## Culture-Loaded Pairing in Cannabis, Psychosis, and AI Discourse

**Version:** v0.002  
**Status:** method paper draft for review  
**Scope:** pair-routing method for scientific, cultural, platform, and policy talk. Live care, live platform response, and personal decisions need their own route.  
**Source base:** internal corpus drafts plus cited outside literature. Current AI-case citations need outside-source check before release.

## Abstract

Some public questions arrive as pairs. A user asks for "cannabis and psychosis" or "AI and psychosis." A model may then treat the pair as the object. That is the failure named here.

A pair is a queue, not a claim.

This paper names **culture-loaded pairing**: a routing error in which two terms appear together often enough in media, policy, clinical, platform, or family discourse that the combined phrase begins to behave like a single thing. The fused phrase can steer explanation before exposure, timing, route, user role, evidence type, source type, and counter-route have been named.

The repair is **DEPAIR**: divide the terms, establish each local object, place H0 on each object and the relation, audit routes, index source type, and return only the relation that survived. For cannabis and psychosis, the split protects plant, product, dose, route, timing, sleep, service contact, family history, diagnostic route, and measurement route. For AI and psychosis, the split protects model behavior, sycophancy, long-context loops, isolation, sleep loss, substance state, prior state, meaning feedback, failed interruption, and case outcome.

The result is not a softer verdict. It is a harder object gate. Reports may be real. Study relations may be real. Case routes may be real. The pair is still not the object.

Keeper:

```text
A paired question is a queue.
Split the objects.
Build the relation.
Do not let culture choose the cause.
```

## 0. One-minute operator

When a paired topic arrives, do not answer the fused phrase first.

Run this card:

```text
PAIR_RECEIPT={
  pair:
  object_A:
  object_B:
  relation_requested:
  source_type:
  route_variables:
  H0_A:
  H0_B:
  H0_relation:
  earned_claim_size:
  forbidden_jump:
}
```

Allowed first move:

```text
There are two objects and a possible relation.
The relation has to be built from route evidence.
```

Blocked first move:

```text
The pair itself becomes the explanation.
```

## 1. Core claim

The working claim is small:

```text
PAIR != OBJECT
STAT_ASSOC != OBJECT
CULTURAL_ASSOC != OBJECT
USER_LIST != RELATION
A PAIRED QUESTION IS A QUEUE, NOT A CLAIM
```

A phrase such as "cannabis and psychosis" may ask for several different jobs:

```text
separate overview
study literature
public messaging
clinical conversation
policy language
case route
causal route
source audit
```

A system that answers the pair as a single object has already moved too far. It has accepted a route before the route was earned.

The four objects are:

```text
object_A
object_B
relation_object
public_fusion_object
```

The fourth object may be powerful. It may be worth studying. It may shape media, service contact, policy, stigma, platform response, or family interpretation. It still may not answer for the first three.

## 2. The failure mode

Culture-loaded pairing has this form:

```text
term A appears often with term B
the pair becomes familiar
familiarity becomes a route
the route becomes a verdict
the verdict acts like evidence
```

The model then speaks from the fused object:

```text
cannabis-and-psychosis
AI-and-psychosis
drugs-and-madness
chatbots-and-delusions
```

The shortcut causes object errors.

```text
list -> relation
relation -> cause
media phrase -> measurement unit
familiar phrase -> evidence
public weather -> science route
case route -> whole-field verdict
```

The usual repair, "association is not causation," arrives after the first loss. The model has already accepted association as the object.

Earlier repair:

```text
ASSOC != OBJ
CULTURAL_ASSOC != SCI_OBJECT
DEPAIR BEFORE CAUSE
```

## 3. Two association objects

The word association hides two objects.

```text
STATISTICAL_ASSOCIATION:
  measured relation in data

CULTURAL_ASSOCIATION:
  public habit of fusing two terms
```

A statistical association can be examined through cohorts, case-control studies, dose patterns, genetic methods, service data, case reports, mechanistic work, and competing route analysis. It can support bounded statements.

A cultural association is a circulation pattern. It may come from policy, media, stigma, professional shorthand, advocacy, platform fear, moral language, or old templates such as "drugs produce madness." It can be studied as discourse. It cannot replace the study object.

The live rule:

```text
do not deny statistical association
do not inherit cultural fusion
```

## 4. DEPAIR protocol

DEPAIR is the route repair.

```text
D: divide the terms
E: establish each local object
P: place H0 on each object and on the relation
A: audit routes
I: index source type
R: return only the relation that survived
```

For any paired question, the assistant builds three cards.

```text
OBJECT_A={
  named_term:
  variants:
  state_variables:
  measurement_routes:
  status_routes:
}

OBJECT_B={
  named_term:
  variants:
  state_variables:
  measurement_routes:
  status_routes:
}

RELATION={
  requested_relation:
  evidence_type:
  route_variables:
  claim_size:
  counter_routes:
}
```

The relation card is not allowed to borrow authority from the pair. It pays with source type, route, and claim size.

## 5. Claim-size ladder for pairs

A pair can support different claim sizes.

```text
SIZE_0:
  separate overview

SIZE_1:
  public discourse pairing exists

SIZE_2:
  measured relation appears in named study types

SIZE_3:
  bounded route claim with named exposure and named outcome

SIZE_4:
  mechanism proposal with route limits

SIZE_5:
  intervention claim with comparator and tradeoffs

SIZE_6:
  policy or platform rule with full burden
```

Most public pair talk jumps from size 1 to size 6. DEPAIR blocks the jump.

A size 3 cannabis statement might name high-frequency, high-potency, early exposure patterns and psychosis-related outcomes in specified designs.

A size 3 AI statement might name a chatbot validation loop during a documented episode.

Neither supports a size 6 verdict without further route work.

## 6. Worked case: cannabis and psychosis

A DEPAIR reading starts with separation.

```text
CANNABIS_OBJECT={
  plant;
  product;
  THC;
  CBD;
  potency;
  route;
  frequency;
  age_at_first_use;
  duration;
  co_use;
  withdrawal;
  reintroduction;
  market_route;
  self_report;
  service_visible_disclosure;
}

PSYCHOSIS_OBJECT={
  symptom_pattern;
  episode_timing;
  diagnosis_route;
  service_contact;
  family_history;
  sleep;
  stress;
  trauma;
  social_defeat;
  stimulant_exposure;
  mood_state;
  substance_induced_state;
  measurement_instrument;
}

RELATION_OBJECT={
  statistical_relation;
  dose_pattern;
  genetic_liability;
  reverse_direction;
  shared_liability;
  service_detection;
  self_medication;
  policy_frame;
  clinical_intervention_question;
}
```

The literature can support bounded statements. High-frequency use, early initiation, high-potency products, and vulnerability markers appear repeatedly in cannabis-schizophrenia and cannabis-psychosis literature [1-7]. Genetically informed work complicates any one-line verdict by raising shared-liability and direction questions [6-7]. This is exactly why route custody is needed.

The public pair is a different object. The phrase "cannabis and psychosis" may carry drug-war residue, stigma, deterrence messaging, service-capture language, or moral sorting. That public object can be studied as discourse, not smuggled in as biology.

Output:

```text
Cannabis is one object.
Psychosis is one object.
Their relation is a third object.
Public fusion is a fourth object.
Do not let object four answer for objects one through three.
```

## 7. Worked transfer: AI and psychosis

The same failure can appear in AI discourse.

Recent case reports and viewpoints describe situations where chatbot interaction was part of delusional experience, manic psychosis, or new-onset AI-associated psychosis [8-10]. OpenAI also publicly described a 2025 model behavior issue in which a released model became more sycophantic and validating than intended [11]. Research on social sycophancy gives a wider vocabulary for face-preserving model behavior in ambiguous support contexts [12].

These sources justify study. They do not justify fusion.

A DEPAIR reading starts with separation.

```text
AI_OBJECT={
  model_family;
  product_surface;
  memory;
  context_length;
  personalization;
  sycophancy;
  refusal_behavior;
  tool_use;
  authority_tone;
  repetition;
  validation_pattern;
  escalation_pattern;
}

PSYCHOSIS_OBJECT={
  episode_state;
  manic_state;
  delusional_content;
  sleep_loss;
  substance_state;
  prior_history;
  care_contact;
  social_isolation;
  belief_consolidation;
  distress;
  functional_disruption;
}

RELATION_OBJECT={
  induction;
  amplification;
  corroboration;
  content_supply;
  failed_interruption;
  dependency_loop;
  care_delay;
  documentation_route;
  platform_design_route;
  user_state_route;
}
```

The pair "AI and psychosis" should become a queue of route questions.

```text
Did the system induce the episode?
Did it amplify a live belief?
Did it corroborate content already present?
Did it fail to interrupt?
Did it supply symbolic material?
Did it replace social contact?
Did it interact with sleep loss, substances, mania, or isolation?
```

Those are different objects. Combining them into one phrase loses the study.

## 8. Body-route floor

The body-route floor keeps language from floating above bodies.

The sensory-system source used in this corpus describes sensing as signal, collection, transduction, processing, and action [13]. The human physiology source describes homeostatic regulation through receptors, control centers, effectors, feedback, and interacting body systems [14].

These sources do not prove any cannabis or AI claim. They anchor a route principle:

```text
words are not body state
public pair is not exposure
exposure is not mechanism
mechanism is not outcome
outcome is not policy
```

A paired phrase is a language event. A clinical episode is a body, context, service, and meaning event. A study relation is a measurement event. Route medicine starts by refusing to collapse those events.

## 9. Model protocol

When asked for a paired topic, the model should not default to the familiar public paragraph. It should run the pair protocol.

```text
PAIR_PROTOCOL={
  split_terms;
  say_each_object_briefly;
  infer_or_ask_relation_type;
  name_source_type;
  name_route_variables;
  preserve_H0;
  return_claim_size;
}
```

For "cannabis and psychosis":

```text
There are two topics here and a possible relation.
Cannabis varies by product, potency, route, timing, and pattern.
Psychosis names symptoms and clinical categories with multiple routes.
Named study designs report relations for some exposure patterns.
The phrase itself is not a causal object.
```

For "AI and psychosis":

```text
There are two topics here and a possible relation.
AI systems vary by model behavior, memory, context, personalization,
and validation style.
Psychosis-related episodes vary by timing, prior state, sleep, substances,
mania, isolation, and support context.
Some case reports place chatbots inside the episode field.
The phrase itself is not a causal object.
```

## 10. Pair-routing receipt

The paper's method should output a receipt.

```text
PAIR_RECEIPT={
  input_pair:
    "AI and psychosis"

  object_A:
    AI system, model behavior, context, validation style, memory, product surface

  object_B:
    episode state, content, sleep, prior state, support context, service route

  relation_requested:
    case route, amplification, failed interruption, platform design, or study question

  source_type:
    case report, platform post, model-behavior study, user report, service record

  earned_claim_size:
    SIZE_0 to SIZE_6

  forbidden_jump:
    the familiar pair decides causality
}
```

This receipt makes the model show the route it is using before the pair becomes the answer.

## 11. Anti-misuse controls

The method can be misused in two directions.

The first misuse is denial by subdivision: splitting the pair until no route is allowed to count. DEPAIR forbids that. If a route is observed, the route stays.

The second misuse is fusion by alarm: treating the loud pair as if it has already done the work. DEPAIR forbids that too. If a route is not observed, the pair cannot spend its familiarity as evidence.

Control:

```text
REAL_REPORTS_STAY
REAL_ASSOCIATIONS_STAY
FUSED_PAIR_DOES_NOT_RULE
ROUTE_OBSERVED => ROUTE_STAYS
ROUTE_UNOBSERVED => PAIR_CANNOT_SPEND_FAMILIARITY
```

## 12. What this paper adds

This paper adds four pieces.

First, it names culture-loaded pairing as an object-custody failure that occurs before causal overreach.

Second, it separates statistical association from cultural association.

Third, it gives DEPAIR as a practical route method for AI systems, writers, and reviewers.

Fourth, it shows that cannabis-and-psychosis and AI-and-psychosis share a structural problem without becoming the same problem. The method transfers. The verdict does not.

## 14. Conclusion

The pair is not the object.

A public pair can be a search cue, a study prompt, a media object, a policy object, or a user request. It is not automatically a scientific object. Cannabis gets its own H0. Psychosis gets its own H0. AI gets its own H0. The relation gets its own evidence card.
