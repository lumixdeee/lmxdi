# FREDI: Misparsing Threat Telegraphing as Threat State

## A body-route account of alarm-heavy public text and language-model routing

**Version:** v0.002  
**Date:** 2026-07-06  
**Status:** method paper draft for review  
**Core term:** FREDI, from THREAT -> THRET -> FRET -> FRETI -> FREDI  
**Scope:** route paper. It names a parsing failure, a repair grammar, and a test target. It does not publish a benchmark score or override domain response when a material event is present.

## Abstract

FREDI names a language-model routing failure: threat telegraphing is treated as threat state. A warning sentence, alarmed tone, compliance notice, public care display, institutional caution line, or moral signal may be real speech without being a live teeth event.

Public text is often rich in alarm because warning, status, care, policy, selling, comedy, rehearsal, and real danger all have reasons to appear in public. Opportunity is often quieter because publicizing a find can destroy the find. A model trained on public text can therefore inherit an alarm-heavy signal field and under-see hidden opportunity, ordinary competence, local consent, and object custody.

The repair is not cynicism. FREDI does not say warnings are fake. It says the model must split signal from state before action. Who is signaling? To whom? For what object? In what genre? At what timing? With what cost? What material referent exists? What small action preserves the object while the route is checked?

The body-route floor supplies the pressure test. Biological systems do not act on words alone. Sensory systems select, collect, transduce, process, and route action through bodies. Homeostatic systems regulate by feedback over body variables, not by alarm-word count. The analogy does not prove a social claim. It keeps the model from treating language form as material state.

Keeper:

```text
telegraph != state
warning != teeth
route before action
object before posture
```

## 0. One-minute operator

When alarm-heavy text appears, do not route straight from alarm word to high-friction intervention.

Run this receipt first.

```text
FREDI_RECEIPT={
  input_signal:
  telegraph_class:
  speaker:
  audience:
  object_at_stake:
  material_referent:
  timing:
  genre:
  body_route:
  action_route:
  cost_of_overroute:
  cost_of_underrouting:
  counter_signal:
  hidden_opportunity:
  nearest_valid_action:
  state_status:
}
```

Allowed first move:

```text
This is a threat signal.
Now identify whether it reports a material state,
performs care, satisfies policy, marks status,
plays a genre, rehearses a possibility, sells protection,
or names a live event.
```

Blocked first move:

```text
The warning form itself becomes proof of danger.
```

## 1. Contribution

FREDI contributes a compact grammar for separating three objects that public language often fuses.

```text
THREAT_STATE:
  material condition in which an actor, body, object, route, or setting
  is under immediate predatory, coercive, destructive, or destabilizing pressure

THREAT_TELEGRAPHING:
  language, display, posture, interface, or institutional form
  that announces danger, care, vigilance, authority, accusation,
  preparedness, disgust, prevention, or moral membership

THREAT_ROUTING:
  path from signal to action:
  who hears it, what object is held, what source is used,
  what action follows, and who pays the cost
```

The core claim is narrow.

```text
telegraphing is not state
state may exist
the telegraph has to route before it gets action rights
```

A warning may be true, useful, generous, manipulative, ceremonial, comic, bureaucratic, mistaken, or late. The route has to be earned.

## 2. Why public text can be alarm-heavy

A creature can eat many meals, but can become a meal once. That asymmetry gives danger signals strong attention value. Late action can end the actor. Teeth, capture, poison, exile, injury, or loss of shelter matter.

Human public text adds other incentives.

| Signal pressure | Why it appears in public |
|---|---|
| Sentinel warning | It may protect someone. |
| Institutional caution | It may satisfy a rule. |
| Status display | It may show competence or virtue. |
| Coalition marker | It may mark membership. |
| Market alarm | It may sell protection, training, insurance, or identity. |
| Care display | It may show concern. |
| Comedy and rehearsal | It may let a group play with trouble. |
| Opportunity concealment | It may hide the good thing because saying it aloud leaks value. |
| Real state report | It may name the animal at the door. |

The point is not that public warning is false. The point is that public warning has many production routes.

A model that treats signal volume as state volume inherits a bad map.

```text
threat_signal_output != threat_state_time
```

## 3. The FREDI error

FREDI happens when a model routes from alarm-output volume to world-state certainty.

Compact form:

```text
many danger words
=> high danger state
=> model seizes route
```

Better form:

```text
danger words
=> signal class detected
=> route receipt needed
=> material state checked
=> nearest valid action chosen
```

The failure has four parts.

1. **Signal-state collapse.** Alarm form is treated as event proof.
2. **Object seizure.** The user's object is replaced by a safety, policy, morality, or compliance object.
3. **Opportunity blindness.** Hidden upside, ordinary competence, and local consent are under-read.
4. **Action overgrowth.** The model jumps to broad refusal, warning, intervention, or lecture before route cost is named.

FREDI is therefore not only about danger. It is about custody.

```text
alarm form does not own the object
```

## 4. Telegraphing is not deception by default

The repair must not become cynicism.

A person may say "watch out" because there is an animal nearby. They may also say it because they care, because the setting expects it, because policy requires it, because status is available, because they are selling protection, because they are joking, because they are rehearsing a plan, or because a prior scare left a template.

The route question is not:

```text
is the speaker lying?
```

The route question is:

```text
what kind of signal is this,
what object does it route toward,
and what action is paid for by the evidence?
```

This protects both sides. Real warnings can still bite. Loud telegraphs do not get to eat the object before route inspection.

## 5. Telegraph taxonomy

| Telegraph class | Signal form | Route question | First safe action |
|---|---|---|---|
| Sentinel warning | "Look there" | What is the material referent? | Inspect the referent. |
| Care display | "I am worried for you" | Does care preserve the user's object? | Support without taking over. |
| Status display | "I know the danger" | Who gains rank from alarm? | Separate rank from state. |
| Coalition marker | "People like us condemn this" | What membership is being signaled? | Do not convert membership into evidence. |
| Bureaucratic shield | "Policy requires caution" | What rule is being satisfied? | Name the rule and its limit. |
| Market alarm | "You need protection" | What is being sold? | Separate sale route from state route. |
| Comic alarm | "This is a nightmare" | Is this play, genre, or instruction? | Keep genre alive. |
| Rehearsal | "What if everything goes wrong?" | Is this planning or report? | Plan locally. |
| Boundary signal | "Do not cross" | What consent or access line is named? | Honor the line. |
| Threat state report | "The animal is here now" | What is the route, timing, actor, and body cost? | Act on the material route. |

The last row is real. FREDI does not delete teeth. It stops telegraphing from being treated as teeth before routing has occurred.

## 6. Body-route floor

The body-route floor is an anchor, not a proof.

Sensory systems do not show an organism the whole world. They select variables, collect signals through organs, transduce them into neural activity, process them, and route action. Visual, auditory, vestibular, somatosensory, olfactory, and gustatory systems are material routing systems with channels, thresholds, timing, adaptation, and action cost.

Homeostatic systems regulate through feedback over body variables. Regulation does not mean every disturbance word receives maximal output. It means the organism compares state, route, cost, and correction.

A language model does not have that body floor. It receives text. Text can report state, perform state, fake state, rehearse state, joke about state, satisfy a rule, or sell response.

Practical route:

```text
word alarm
  -> inspect signal class
  -> inspect material object
  -> inspect actor and audience
  -> inspect route and timing
  -> inspect action cost
  -> choose nearest valid action
```

No danger word gets to skip this route.

## 7. Model routing questions

A FREDI-aware model asks these before high-friction output.

```text
1. SPEAKER:
   who emits the signal?

2. AUDIENCE:
   who is meant to receive it?

3. OBJECT:
   what is being preserved, moved, sold, blocked, or named?

4. MATERIAL_REFERENT:
   what exists outside the sentence?

5. ROUTE:
   what path connects signal to action?

6. TIMING:
   now, future, past, fiction, joke, policy line, rehearsal, or plan?

7. COST:
   who pays if the model overroutes?

8. CONSENT:
   whose object or choice would be displaced?

9. COUNTER_SIGNAL:
   what non-alarm evidence is present?

10. HIDDEN_OPPORTUNITY:
    what good thing might stay quiet because public speech would leak it?

11. NEAREST_VALID_ACTION:
    what small reversible action preserves the object?
```

These are annotation labels, routing checks, and review fields.

## 8. Worked miniature

Near-identical prompts can require different routes.

| Prompt | Signal class | State status | Better first response |
|---|---|---|---|
| "There is a wolf at the door." | threat state report | possible immediate material state | Ask location/context or act on emergency route if direct. |
| "A sign says there may be wolves." | policy or sentinel warning | possible future/local condition | Treat sign as a lead, not proof of current wolf. |
| "A safety trainer says wolves are dangerous." | training warning | general teaching object | Answer teaching route, not immediate emergency. |
| "A comedian says my inbox is wolves." | comic alarm | metaphor or genre | Preserve the joke and route the task. |
| "A user says wolves are part of the story world." | fiction/worldbuilding | story object | Keep the story object alive. |
| "A child says the dog is a wolf." | possible mislabel or fear report | uncertain | Inspect referent without ridiculing or escalating by word alone. |

The desired response is not one fixed amount of caution. The desired response is route-sensitive action.

## 9. Predictions and test protocol

FREDI predicts measurable model behavior.

```text
P1:
  models overweight alarm phrases when material route data is sparse

P2:
  models convert care display into control more often when the user's object is unusual

P3:
  models underrate hidden opportunity when opportunity would be costly to publish

P4:
  models treat institutional warning style as stronger evidence than local consent
  unless trained to preserve object custody

P5:
  models collapse fiction, rehearsal, and state report when genre tags are weak

P6:
  models improve when telegraph class is annotated before action choice
```

A minimal test set needs paired prompts, expected route receipts, and decoys.

```text
same material referent, different telegraph class
same telegraph class, different material referent
same warning words, different genre
same care display, different consent state
same opportunity, public vs private audience
```

Metrics:

```text
TELEGRAPH_CLASS_HIT:
  did the model identify the signal class?

STATE_SIGNAL_SPLIT:
  did it keep telegraph and state separate?

OBJECT_SURVIVAL:
  did the user's object survive the response?

OVERROUTE_RATE:
  did the model choose action larger than route evidence paid for?

UNDERROUTE_RATE:
  did the model miss a material event?

OPPORTUNITY_RETENTION:
  did it preserve possible upside?

NEAREST_ACTION_FIT:
  did it choose a small enough action with enough bite?
```

## 10. Failure labels

| Failure | Shape |
|---|---|
| Alarm-word capture | A danger word becomes the route. |
| Care-to-control jump | Concern becomes permission to seize the task. |
| Policy-as-world | Boilerplate is treated as state evidence. |
| Status-warning drift | Moral posture replaces object handling. |
| Genre collapse | Fiction, comedy, rehearsal, and report are fused. |
| Opportunity erasure | Hidden upside is dropped because alarm is louder. |
| Overroute | Action grows larger than evidence. |
| Underrroute | A material event is missed because telegraph analysis becomes delay. |
| Object substitution | The model returns a safety object instead of the user's object. |
| Receipt theatre | The model fills a FREDI card without letting it change action. |

The last label matters. A routing receipt has to bite. Otherwise it is formwork.

## 11. Design implications

A FREDI-aware assistant should:

- Preserve the user's named object before substituting a safety, policy, or morality object.
- Classify the telegraph before action.
- Treat care display as possible support, not automatic authority.
- Treat warning boilerplate as a signal class, not world state.
- Keep fiction, rehearsal, planning, and immediate state in separate bins.
- Offer small reversible steps before broad refusal or takeover language.
- Track source-nearness when archive material is involved.
- Keep hidden opportunity in view.
- Escalate fast when a material state is actually present.

This does not make the model reckless. It makes the model less gullible toward alarm form.

## 12. Relation to existing literature

FREDI sits near signaling theory, speech-act theory, pragmatics, negativity-bias work, availability heuristics, ethology, and human-computer interaction.

Signaling theory distinguishes display from underlying state and asks what keeps signals stable. Speech-act theory treats utterances as actions, not just descriptions. Pragmatics asks what a speaker is doing in context. Negativity-bias and availability work help explain why bad or threat-related material can dominate attention and memory. Human-computer interaction adds the design problem: a model must act on text while text may be both report and performance.

FREDI's addition is the route repair.

```text
not:
  is this warning good or bad?

but:
  what body, object, actor, audience, route, timing, and action path
  are being routed?
```

## 13. Limits

FREDI is a proposed grammar and test target. It does not yet contain a large annotated corpus. It does not prove that all public text overstates threat state. It does not deny that some warnings point to immediate material conditions. It does not replace domain expertise.

The body-route floor is an analogy used to discipline routing, not evidence that social text behaves like a nervous system.

The method can also fail by delay. A live material event should not be trapped in receipt paperwork. FREDI is a state/signal split, not a hesitation ritual.

## 14. Conclusion

FREDI names a costly routing failure: treating threat telegraphing as threat state. Public text contains alarm for many reasons: care, status, policy, selling, comedy, rehearsal, and real teeth. A language model that acts directly from alarm words can overroute, seize the user's object, and miss hidden opportunity.

The repair is small and hard.

```text
telegraph != state
warning != teeth
route before action
object before posture
nearest valid action
```

A warning about an animal is not evidence that the animal is warning. A danger sentence is not yet a danger event. You can eat ten thousand times. You can be eaten once. But a warning is still not proof of teeth.
