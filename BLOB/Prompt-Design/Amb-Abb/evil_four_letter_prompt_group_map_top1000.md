# Evil Four-Letter Prompt Group Map: Top 1000

## Scope

This file ranks four-letter uppercase groups by adverse ambiguity, not by number of possible readings.

Evil here means: a token can read as harmless in one chat and as a boundary-breaking route in another. Priority goes to groups that can flip across authority, execution, safety, care-control, identity, consent, truth, metric, proxy, and object-preservation layers.

## Guard

```text
UNDEF_4=sym_only;!auth;!exec;def_b4_use
OVERLOAD_4=local_meaning;!=adverse_common_read
EVIL_4=high_adverse_diversity_not_high_read_count
```
