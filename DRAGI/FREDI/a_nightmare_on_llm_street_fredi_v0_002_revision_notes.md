# FREDI v0.002 revision notes

## What changed

The v0.001 object survived. v0.002 adds the stronger July 2 analysis:

```text
many meals / one meal
threat-signal output vs threat-state time
human threat telegraphing vs animal threat response
threat talk as possible opportunity move for the speaker
FREDI = fear-reward display inversion
```

## Main correction

The paper now avoids treating the threat imbalance as one simple animal law.

Better handling:

```text
overt opportunity signals often leak value
threat signals can have audience value
the balance varies by species and context
human public text amplifies threat display
LLM training can misread display as state
```

## Claims now fenced

The new version does not publish fixed percentages for all human output. It treats the output/time imbalance as a testable prediction:

```text
threat_signal_output >> threat_state_time
```

That is stronger than guessing a universal percentage.

## Strongest keeper lines

A warning about an animal is not evidence that the animal is warning.

A danger sentence is not yet a danger event.

You can eat ten thousand times.
